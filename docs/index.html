如何取得 GitHub PAT

PAT 是什麼？

Personal Access Token 讓這個頁面代替你操作 GitHub API。Token 只在你這次操作期間存在於瀏覽器記憶體，不會被儲存。

推薦 方法一：Classic token（最簡單）

連結
https://github.com/settings/tokens/new
  • 選 Generate new token (classic)
  • Note 隨意填
  • Expiration 建議 30 或 90 天
  • Scopes 只勾 repo 一項
  • 複製 ghp_ 開頭的 token

方法二：Fine-grained token

連結
https://github.com/settings/personal-access-tokens/new

Repository permissions 必須勾兩個：

  • Administration：Read and write（建立倉庫）
  • Contents：Read and write（上傳檔案）

漏勾 Administration 就會出現「Resource not accessible」錯誤。

安全提醒

這個頁面不會儲存你的 PAT。如果 token 外洩，到 GitHub 設定頁刪除後重發即可。
